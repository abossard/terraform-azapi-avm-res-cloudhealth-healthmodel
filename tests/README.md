# Tests

`tests/unit` contains mocked public-boundary Terraform tests for the root module and independently consumable child submodules. `tests/resource-types.sh` inspects the verbose root plan to prove all nested child resource type overrides reach their resources. `tests/azapi-resource-compliance.sh` verifies the fixed inventory of module-owned AzAPI resources, one explicit `replace_triggers_refs` assignment per block, and each exact immutable path set; its mutation suite is a prerequisite of `pr-check`. `tests/integration` uses real providers to prove relationship and role-assignment replacement semantics. The role-assignment wrapper machine-checks Terraform's JSON plan for exactly one `["delete", "create"]` action on both principal and description mutations and is a prerequisite of `tf-test-integration`. The customer examples are the Azure-backed apply, idempotency, and destroy acceptance suite.
